Changelog

This page tracks API changes, new features, and deprecations across Hesai lidar firmware and SDK releases. Entries are listed in reverse chronological order.

note

This changelog covers developer-facing API and SDK changes. For full firmware release notes, refer to the downloads section on the Hesai website.

1 How to Check Your Firmware Version​

HTTP API (Pandar / QT / XT series):

local_url = 'http://' + ipaddr + '/pandar.cgi?action=get&object=device_info'

The response Body includes FW Ver and SW Ver fields.

LidarUtilities: Connect to the lidar → the firmware version is displayed in the device info panel.

2 API Changelog​

2.1 v2.x (Current)​

2024-Q4 — XT32M2X Firmware 2.x

  • Added: dual return mode configuration via HTTP API (lidar_mode=2)
  • Added: Expanded device_info response — now includes Up_Fpga_Ver, LargeCodeRange, Codewheel_cal
  • Changed: AccAnglePhase and AccAnglePeak fields added to device_info
  • Fixed: Intermittent HTTP response timeout on high-traffic networks

2.2 v1.x​

2023-Q2 — Initial Serial API support (JT16)

  • Added: Serial API over RS232/RS485 for JT16 lidar
  • Added: CMD datagrams with CRC-32/MPEG-2 checksum
  • Added: ACK datagram with Fault Code field (0 = success)
  • Added: Switch motor speed command (CMD ID 0x03)

2022-Q3 — HTTP API GA

  • Added: HTTP GET/SET interface at /pandar.cgi
  • Added: get device_info, get lidar_config, set lidar_data actions
  • Added: Supported on Pandar series, QT series, XT series
