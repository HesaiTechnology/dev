SDKs & Drivers

Hesai provides open-source SDKs and ROS drivers for integrating lidar point cloud data into your applications. All repositories are hosted on GitHub under the HesaiTechnology organization.

1 Available SDKs​

1.1 HesaiLidar General SDK​

A C++ SDK for receiving and decoding point cloud data from Hesai lidars over UDP.

LanguageC++
GitHubHesaiTechnology/HesaiLidar_General_SDK
Supported ModelsPandar series, QT series, XT series
OutputDecoded point cloud (XYZ + intensity + timestamp)
PlatformLinux, Windows

Quick start:

git clone https://github.com/HesaiTechnology/HesaiLidar_General_SDK.git
cd HesaiLidar_General_SDK
mkdir build && cd build
cmake .. && make -j$(nproc)

1.2 HesaiLidar ROS Driver​

A ROS 1 wrapper around the General SDK. Publishes sensor_msgs/PointCloud2 topics compatible with RViz, Cartographer, and other ROS tools.

LanguageC++
GitHubHesaiTechnology/HesaiLidar_General_ROS
ROS VersionROS 1 (Melodic / Noetic)
Supported ModelsPandar series, QT series, XT series
Outputsensor_msgs/PointCloud2

Quick start:

cd ~/catkin_ws/src
git clone https://github.com/HesaiTechnology/HesaiLidar_General_ROS.git
cd ~/catkin_ws && catkin_make
source devel/setup.bash
roslaunch hesai_lidar hesai_lidar.launch lidar_type:=PandarQT64

See Visualize Point Cloud with ROS & RViz for a full setup guide.

1.3 HesaiLidar ROS2 Driver​

A ROS 2 port of the General SDK. Publishes sensor_msgs/PointCloud2 topics for use with RViz2 and Nav2.

LanguageC++
GitHubHesaiTechnology/HesaiLidar_General_ROS2
ROS VersionROS 2 (Foxy / Humble / Iron)
Supported ModelsPandar series, QT series, XT series
Outputsensor_msgs/PointCloud2

Quick start:

cd ~/ros2_ws/src
git clone https://github.com/HesaiTechnology/HesaiLidar_General_ROS2.git
cd ~/ros2_ws && colcon build
source install/setup.bash
ros2 launch hesai_ros_driver hesai_ros_driver.launch.py lidar_type:=XT32
