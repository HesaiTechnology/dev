SDK 与驱动程序

禾赛提供开源 SDK 和 ROS 驱动，用于将激光雷达点云数据集成到您的应用程序中。所有仓库均托管在 GitHub HesaiTechnology 组织下。

1 可用 SDK​

1.1 HesaiLidar General SDK​

用于通过 UDP 接收并解码禾赛激光雷达点云数据的 C++ SDK。

语言C++
GitHubHesaiTechnology/HesaiLidar_General_SDK
支持型号Pandar 系列、QT 系列、XT 系列
输出解码点云（XYZ + 强度 + 时间戳）
平台Linux、Windows

快速开始：

git clone https://github.com/HesaiTechnology/HesaiLidar_General_SDK.git
cd HesaiLidar_General_SDK
mkdir build && cd build
cmake .. && make -j$(nproc)

1.2 HesaiLidar ROS 驱动​

基于 General SDK 的 ROS 1 封装，发布与 RViz、Cartographer 等 ROS 工具兼容的 sensor_msgs/PointCloud2 话题。

语言C++
GitHubHesaiTechnology/HesaiLidar_General_ROS
ROS 版本ROS 1（Melodic / Noetic）
支持型号Pandar 系列、QT 系列、XT 系列
输出sensor_msgs/PointCloud2

快速开始：

cd ~/catkin_ws/src
git clone https://github.com/HesaiTechnology/HesaiLidar_General_ROS.git
cd ~/catkin_ws && catkin_make
source devel/setup.bash
roslaunch hesai_lidar hesai_lidar.launch lidar_type:=PandarQT64

完整配置说明请参见 使用 ROS 与 RViz 可视化点云。

1.3 HesaiLidar ROS2 驱动​

General SDK 的 ROS 2 移植版，发布 sensor_msgs/PointCloud2 话题，可与 RViz2 和 Nav2 配合使用。

语言C++
GitHubHesaiTechnology/HesaiLidar_General_ROS2
ROS 版本ROS 2（Foxy / Humble / Iron）
支持型号Pandar 系列、QT 系列、XT 系列
输出sensor_msgs/PointCloud2

快速开始：

cd ~/ros2_ws/src
git clone https://github.com/HesaiTechnology/HesaiLidar_General_ROS2.git
cd ~/ros2_ws && colcon build
source install/setup.bash
ros2 launch hesai_ros_driver hesai_ros_driver.launch.py lidar_type:=XT32

2 型号支持矩阵​

各 SDK 支持哪些激光雷达型号的完整对照表，请参见型号兼容性速查表。
