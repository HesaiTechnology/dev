错误码参考

本页列出禾赛激光雷达各 API 返回的错误码与故障码，用于诊断异常的 API 响应。

备注

实际故障码定义因型号与固件版本而异，请以具体产品的 API 手册为准。

1 HTTP API 错误码​

HTTP API 响应的 JSON Head 对象中包含 ErrorCode 字段：

{"Head": {"ErrorCode": "0", "Message": "Success"}, "Body": {...}}
ErrorCodeMessage含义建议操作
0Success命令执行成功无
1Invalid parameter请求 URL 中的值或键无效检查 URL 格式；对照 API 手册确认 key 和 value
2Command not supported当前型号不支持该 action/object 组合参阅产品 HTTP API 手册获取支持的命令列表
3Device busy激光雷达正在处理上一条请求稍后重试
4Write failed参数写入 Flash 失败重启激光雷达后重试；若持续出现请联系技术支持

适用型号：Pandar 系列、QT 系列、XT 系列（所有支持 HTTP 服务器的型号）。

2 Serial API 故障码​

Serial API 应答帧（ACK datagram）包含 Fault Code 字段。值为 0x00 表示成功，其他值表示异常。

ACK 帧 → Fault Code 字段（1 字节）
0x00 = 成功
故障码（十六进制）含义建议操作
0x00成功无
0x01命令不支持当前型号或固件版本不支持该 CMD ID
0x02参数无效CMD DATA 数据超出范围或格式错误
0x03CRC 校验错误CMD 帧 CRC 校验失败，请重新发送
0x04设备忙激光雷达正在执行上一条命令，请稍后重试
0xFF未知错误发生未知内部错误，请重启激光雷达；若持续出现请联系技术支持

适用型号：JT16（通过 RS232/RS485 使用 Serial API）。

如何解析 Fault Code

通过帧头（0x24 0x4C 0x44 0x41 0x43 0x4B 0x2C）和帧尾（0xEE 0xFF）在 RS485 数据流中过滤 ACK 帧，然后读取指定偏移处的 Fault Code 字节。完整的 ACK 帧结构请参见 使用 Serial API。

3 TCP API 响应码​

TCP API 响应帧中包含状态字节。

码值含义建议操作
0x00成功无
0x01命令不支持确认该命令在当前型号的 TCP API 手册中存在
0x02参数超出范围参照 API 手册检查参数取值范围
0x03CRC 不匹配重新计算 CRC 并重发

适用型号：Pandar 系列、QT 系列、XT 系列（支持 TCP 命令接口的型号）。

4 通用排查步骤​

收到异常错误码时：

  1. 确认固件版本 — 部分命令对最低固件版本有要求。可通过 HTTP get device_info 等查询命令获取当前固件版本。
  2. 检查型号支持 — 并非所有命令都适用于所有型号。参见型号兼容性速查表。
  3. 验证网络/串口连接 — 连接问题可能导致响应数据异常。参见配置以太网或配置串口。
  4. 查阅产品 API 手册 — 每款激光雷达均附有专属 API 手册，其中包含权威故障码说明表。
